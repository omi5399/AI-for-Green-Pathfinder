# AI for Green - 探路者 (Pathfinder)

🎯 **赛事**：南通大学第一届"AI for Green"人工智能24小时挑战赛
🏆 **赛道**：B赛道 - 开放创新赛道
👥 **团队**：探路者（南通大学计算机专业 + 交设专业跨界组合）

## 🚀 项目简介
本项目深度洞察新能源充电场景痛点，**基于赛方提供的真实充电场站数据**。我们致力于利用LLM大模型与AI Agent技术，打造一款极具交互性与实用价值的**智能数据洞察助手**。我们将冷冰冰的数据转化为直观的业务建议，完成从数据清洗到产品化交互的极速落地。

## 💻 技术栈
- 前端交互：Python / Streamlit (侧重UI美观与用户交互体验)
- 数据分析：Pandas / Pyecharts (数据清洗与可视化)
- AI核心：Kimi / 智谱 / 文心一言 API (LLM自然语言理解与生成)

## 🏗️ 系统架构与核心创新 (System Architecture)
本项目专为新能源充电数据分析场景设计，核心采用 **LLM + AI Agent** 架构：
1. **真实数据接入与清洗**：对赛方提供的充电场站原始数据进行处理，提取关键业务指标（如利用率、峰谷时段）。
2. **AI Agent 智能交互引擎**：将数据分析结果与大模型API结合，实现“用自然语言对话数据”。用户只需提问（如：“周末哪个场站最闲？”），AI即可自动分析并给出业务洞察。
3. **产品化落地与易用性**：注重前端交互设计，降低数据分析门槛，让非技术人员也能轻松看懂充电场站运营状况，辅助决策。

*(注：比赛期间将开源完整的端到端交互代码与UI原型，严格遵守比赛纪律，真实说明AI工具的使用)*
