## 💡 项目愿景
本项目聚焦于绿色低碳场景下的实际痛点，旨在利用大语言模型（LLM）的推理与多模态能力，打造一款高易用性的智能交互助手。具体赛题方向将于开赛现场公布后，在此仓库实时更新。

## 🛠️ 赛前准备工作 (Preparations)
为了在24小时内实现高效交付，团队目前已完成以下前置准备：
- [x] **需求分析**：完成典型低碳场景（如企业碳盘查、校园绿色出行）的痛点调研。
- [x] **技术选型**：前端拟采用 `Python / Streamlit` 快速构建交互界面，后端接入国内主流大模型 API。
- [x] **架构设计**：采用轻量级前后端分离架构，确保 Demo 的可运行性与易用性。

## 👨‍💻 团队分工
- **队长 (Core Developer)**：负责整体架构设计、大模型 API 接入与核心业务逻辑开发，兼路演主讲。
- **队员 (Product & QA)**：负责场景调研、Prompt 调优测试、UI 体验优化及后勤保障。
