## 🚀 项目简介

## 🏗️ 系统架构与核心创新 (System Architecture)
本项目专为双碳场景设计，核心采用 **LLM + AI Agent** 架构：
1. **多模态数据接入**：支持发票、水电费单、物流单据的图像识别（OCR），自动提取碳源数据。
2. **大模型推理引擎**：接入前沿大模型API，通过定制化Prompt实现“碳审计专家”角色扮演，进行逻辑推理。
3. **动态报告生成**：将非结构化数据一键转化为符合国际标准（GHG Protocol）的企业碳盘查报告。
